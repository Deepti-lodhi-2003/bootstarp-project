# Prisma — Modern Digital Agency Website Template

A sleek, responsive, modern digital agency web application crafted with **pure Bootstrap 5.3** and Remix Icons. Built for speed, pixel-perfect responsiveness, and smooth user interactions.

---

## 🌟 Key Highlights & Features

- **Hero Carousel**: High-impact 3-slide hero carousel with smooth crossfade, dark contrast gradient overlays, glassmorphism badges, and trust indicators.
- **Pure Bootstrap 5.3 Architecture**: Clean semantic HTML structured using modern Bootstrap utility classes, grid system, and interactive components.
- **100% Mobile Responsive**: Tested on all modern mobile and desktop viewport sizes with zero horizontal overflow.
- **Services Showcase**: Detailed cards highlighting Web Development, UI/UX Design, Digital Marketing, and Cloud Infrastructure with interactive hover animations.
- **Featured Projects**: Portfolio gallery using Bootstrap cards with image overlays and tags.
- **Client Testimonials & Trust**: Customer feedback carousel with verified review badges and 5-star ratings.
- **Meet Our Team**: Professional team profile grid with designation badges and social media profiles.
- **Interactive Contact Form**: Lead capture contact form with contact detail cards and office location information.
- **Modern Footer**: Multi-column navigation, newsletter subscription, copyright, and smooth back-to-top button.

---

## 🛠️ Built With

- **HTML5**: Semantic and accessible page structure
- **CSS / Bootstrap 5.3**: Native utility classes, flexbox, and responsive grid
- **JavaScript**: Bootstrap bundle with Popper for interactive components (carousel, scroll animations)
- **RemixIcon**: Lightweight, vector icons
- **Google Fonts**: Modern typography (Inter & Plus Jakarta Sans)
